// Overview

Designed a portable enclosure for my ECG Activity Monitoring device — a single integrated PCB carrying RPi Zero W, AD8232 analog front-end, MCP3008 ADC, and the power management chain. The case protects the sensitive analog front-end, secures the 18650 battery, and provides clean I/O cutouts for the 3-lead electrodes, USB-C power, and status LED.

为 ECG 毕设设备设计便携外壳：集成板 + 18650 电池一体化封装。两轮打印迭代 解决卡扣过紧与电池仓公差问题，最终 V2 完美装配。

// Design-for-Printing Specifics

Every feature was dimensioned for reliable FDM output on a 0.4mm nozzle:

Feature Spec Printing Reason
Wall thickness 1.6 mm (4 loops) Stiffness without excessive weight
M2.5 screw boss Ø4.5 outer / Ø2.2 hole Heat-set insert or self-tapping
Snap-fit clip clip thickness 1.0 mm Overhang <45° self-supporting
18650 cavity Ø19.2 × 65.2 mm +0.2mm clearance for cell tolerance
PCB locating studs Ø2.5 × 3 mm ×4 Press-fit board alignment
Electrode hole Ø6 chamfered entry No supports on vertical holes
Vent grille 1.2 mm slots ×30 Below 1.6mm bridge limit

// Print Plan — Split & Orientation

Part Orientation Support Time / Material
Bottom cover Face down None (features up) 3.2 h · PETG 48 g
Top cover Face down None 3.5 h · PETG 52 g
Electrode plate Flat None 1.2 h · PETG 12 g
T-pad Flat None 1.6 h · TPU 20 g

Total ~9.5 h · 132 g across 4 prints — all self-supporting, zero supports required. Layer height 0.16mm for cosmetic top surfaces, 0.20mm for hidden pads.

// Fit-Test Iterations (V1 → V2)

Issue (V1) Root Cause Fix (V2)
Snap clips too tight — lid cracked on assembly Clip interference +0.05mm too small Clip clearance +0.2mm, filleted hook
18650 cell rattled Cavity Ø19.0 too tight from elephants-foot Ø19.2 + 0.4mm bottom chamfer
USB-C slot misaligned 0.3mm Shrinkage across 90mm length Compensated +0.3% XY scale on V2

These iterations are the real value of desktop 3D printing: a 24-hour design-fix-reprint cycle instead of waiting days for outsourcing.
