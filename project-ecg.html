// Overview

Built a portable ECG acquisition system using Raspberry Pi Zero W + MCP3008 ADC + AD8232 (ECG 5 Click) analog front-end, targeting personalized low-intensity activity monitoring for the elderly. Collected 30 × 300s sessions (sitting / arm movement / walking), applied coif4 wavelet threshold denoising, converted signals to CWT scalograms, and classified activities with AlexNet transfer learning — reaching 99.8% in the original thesis (later re-evaluated to 85–93% with a leak-free session-level split).

基于树莓派 + AD8232 生物电模拟前端的便携 ECG 采集系统，面向老年人低强度活动监测。 完成采集 → 去噪 → 时频特征 → 迁移学习分类 → 嵌入式部署的完整闭环。

// Signal Processing Pipeline

Raw ECG is contaminated by 50Hz mains, baseline drift, and motion artifacts. Traditional FIR/IIR filters cannot separate noise that shares a frequency band with the QRS complex. Wavelet denoising decomposes the signal in both time and frequency, then attenuates small high-frequency coefficients (noise) while preserving large ones (QRS morphology).

Mother wavelet chosen by SNR comparison: db4 (21.17dB) < sym6 (21.19dB) < coif4 (21.21dB) → coif4 selected for highest SNR + near-symmetry + high vanishing moments. 

// MATLAB · coif4 stationary wavelet denoising (with 50Hz notch)
[num_d, den_d] = iirnotch(50/(FS/2), 2/(FS/2));   % 50Hz notch
x0 = x_raw - mean(x_raw);                          % de-bias
x0 = filtfilt(num_d, den_d, x0);                   % zero-phase notch
x_den = wden(x0, 'modwtsqtwolog','s','mln', 2, 'coif4');

After denoising, each 400-sample window (1.56s) is converted to a CWT scalogram — a time-frequency image that lets a CNN learn "which frequencies appear when". Scalograms beat raw waveforms in the thesis ablation (same training params) because they expose frequency-domain structure and are more robust to residual noise.

// AI Classification — AlexNet Transfer Learning

Pre-trained AlexNet (ImageNet) was fine-tuned by replacing the last 3 layers with a 3-class head (sitting / arm / walking), with MiniBatchSize=20 · MaxEpochs=5 · InitialLearnRate=1e-4. Low learning rate protects pre-trained low/mid-level features while adapting high-level ones.

⚠️ Data-leakage reflection: the thesis reported 99.8% using random sample-level splits, but overlapping windows from the same 300s session leaked across train/test. Re-evaluating with a session-level split (8 sessions train / 2 test) yields a more honest 85–93%. This is the most valuable lesson of the project: experimental rigor matters more than a headline number. 

// MATLAB · session-level split (fixes data leakage)
rng(42);
train_sess = sort(randperm(10, 8));   % 8 sessions for training
test_sess  = setdiff(1:10, train_sess); % 2 held-out sessions
% assign each 400-sample window by its source session id

// Heart Rate Extraction (Pan-Tompkins)

Added classic Pan-Tompkins QRS detection to extract HR from the denoised signal — turning the system from a pure classifier into a richer physiological monitor (HR as 2nd modality): 

// MATLAB · Pan-Tompkins QRS detection skeleton
[b,a] = butter(2, [5 15]/(fs/2), 'bandpass');   % QRS band
x  = filtfilt(b,a,ecg);
d  = diff([0; x]);                              % derivative
s  = d.^2;                                      % squaring
y  = conv(s, ones(30,1)/30, 'same');            % moving window
[~, locs] = findpeaks(y, 'MinPeakHeight', thr, 'MinPeakDistance', 0.25*fs);
hr_bpm = 60 ./ diff(locs) / fs;                 % RR interval → BPM

// Embedded Deployment — TFLite INT8 Quantization

The thesis goal "deploy to Raspberry Pi" was completed post-thesis with a TFLite INT8 quantization plan. Since the Pi Zero W has a single-core ARM11 @1GHz (no GPU/NPU), INT8 is mandatory for usable latency:

Metric FP32 INT8 Quantized
Model size ~244MB ~61MB
Inference / frame ~3–5s ~1.5s
Accuracy (session-level) ~93% ~90% (<3% loss)
Real-time vs frame period (1.56s) FAIL PASS (pipeline < 1.56s)

Next-step optimization: MobileNetV2 (5–10× faster) or 1D-CNN directly on raw signal.

// Power Delivery — Battery Design

The original thesis rig powered the Pi from random power banks (one even output 3V, failing to boot the Pi Zero W). For the standalone device I designed a proper battery power chain. The system is a sensitive analog front-end + digital SoC mix, so the supply is split into a "dirty" digital rail and a "clean" analog rail:

DW01A + 8205A Battery protection Over-charge 4.3V / over-discharge 2.4V / over-current
MP3429 / XL6009 Boost 3.7V → 5V ~85% eff · 5V/2A · 0.3A quiescent-bounded
LP5907 Low-noise LDO 5V→3.3V 10µV noise · >80dB PSRR @1kHz · SOT-23-5
Load Rail Typical Current Notes
RPi Zero W 5V digital 100mA (idle) · 350mA (peak) Deadline acquisition @256Hz
AD8232 AFE 3.3V analog ~0.5mA (+LED ~5mA) Clean rail, no switching noise
MCP3008 3.3V analog <1mA Vref tied to analog rail

Runtimes: 3000mAh × 3.7V × 85% boost ≈ 9.4Wh ÷ 2W peak ≈ 4–5 h continuous capture — comfortably covers the 30 × 300s session plan (2.5h). The 100mΩ series resistors + 10µF/100nF π-filters on the analog rail keep boost switching ripple off the AD8232 supply pin.

// PCB Design — Board-Level Integration

Replaced the flying-wire breadboard (the source of the original FYP's wiring reliability issues) with a custom carrier board 56×34mm that hosts the power chain, AD8232 AFE, and MCP3008, while the RPi Zero W sits on top via its 40-pin header.

Signal Net Pin Mapping
ECG analog out AD8232 OUTPUT → MCP3008 CH0 300Ω series + 1nF to GND (anti-alias RC)
SPI clock MCP3008 CLK Pi GPIO11 (SCLK), 1MHz max
SPI MOSI / MISO MCP3008 DIN / DOUT Pi GPIO10 (MOSI) / GPIO9 (MISO)

LED status Pi GPIO → NPN → LED Green power/status LED, 330Ω

Layout rules applied: analog traces 0.3mm minimum, kept ≥5mm from the boost inductor; power rail widened to 0.5mm for 1A; 100nF decoupling on every IC within 2mm of its pin; solid ground pour on bottom layer, split analog/digital with a single 0Ω bridge at the ADC. The board's 4× M2.5 mounting holes align 1:1 with the printed enclosure's locating studs.

Upgrade path: the 10-bit MCP3008 is the weakest link for clinical use — swapping to a 24-bit ADS1299 (same ADS family, used for EEG) would raise resolution from 4.9mV/LSB to sub-µV while keeping the same SPI interface and physically-compatible footprint region.

// Measured & Lessons Learned

Issue discovered during review Severity Fix applied
Sampling rate mismatch: claimed 256Hz, actual ~139Hz (41,742 samples / 300s) 🔴 Critical Deadline-scheduled acquisition, measured 256.0±1Hz
Wavelet inconsistency: thesis said coif4, code used db3 🔴 Critical Unified to coif4 (highest SNR 21.21dB)
Data-split bug: cell(100,10) vs 1-column CSV; 100 vs "1000" chunks 🔴 Critical Single-column + 50%-overlap sliding window, session IDs saved
99.8% accuracy likely inflated by data leakage 🟠 Serious Session-level split → honest 85–93%
"Power bank outputs 3V" — Pi Zero W needs 5V 🟠 Serious 3.7V Li-ion → MP3429 boost 5V → LP5907 LDO 3.3V power tree
Flying-wire breadboard reliability (loose SPI contacts) 🟠 Serious Custom 56×34mm carrier PCB with analog/digital/power zone split
"Goldberger augmented leads" terminology misuse 🟡 Medium Correct term: bipolar limb lead (~Lead I); Goldberger = aVR/aVL/aVF
Deployment goal incomplete in thesis 🟡 Medium Completed TFLite INT8 deployment plan + benchmark
MCP3008 10-bit resolution below clinical 12–16-bit 🟡 Medium Upgrade path: ADS1299 (24-bit biosignal AFE, also used for EEG)
