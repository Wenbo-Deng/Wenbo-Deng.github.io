// Overview

A multi-factor trading analysis tool for the semiconductor equipment ETF (159516), combining technical indicators (ATR/MA/RSI/Bollinger, 30% weight) with fund flow data (主力净流入, 35% weight) to predict T+1 high/low ranges and generate swing-trading recommendations.

基于技术面 + 资金面多因子加权的 ETF 做T分析工具，输出次日高低点区间预测。

// Factor Weighting Model

Factor Indicator Weight
MA Trend 5/10/20-day moving averages 30%
Fund Flow 主力净流入 (institutional flow) 35%
Bollinger Bands 20-day ±2σ 15%
RSI 14-period 10%
Sector ETF fund flow proxy 10%

// Correlation Analysis

Conducted a statistical study: retail investor fund flow vs next-day ETF returns over 34 trading days (Jun 17 – Aug 4, 2026).

Metric Value Interpretation
Correlation (T-day flow vs T+1 return) r = 0.2718 Weak positive correlation
p-value 0.1101 Not significant (limited sample)
Control: flow vs same-day index r = −0.7472 Strong negative (dumb money effect)
Inflow days → next-day up rate 55% Avg +0.17%
Outflow days → next-day up rate 33% Avg −2.14%

Key finding: retail inflow days showed 22pp higher next-day up rate vs outflow days, suggesting a weak predictive signal worth monitoring.

// Sample Code — Weighted Scoring

def calculate_score(technical, fund_flow, boll, rsi, sector):
    score = (
        W_MA_TREND   * technical +
        W_FUND_FLOW  * fund_flow +
        W_BOLL       * boll +
        W_RSI        * rsi +
        W_SECTOR     * sector
    )
    return score  # 0-100, >60 → buy, <40 → sell
