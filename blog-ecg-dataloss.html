99.8% 是错的：一次 ECG 机器学习的数据泄漏反思

Deng Wenbo · Biosignal · AI · Signal Processing · ~8 min read

我的毕业设计用 AlexNet 迁移学习对 ECG 活动分类，论文报告准确率 99.8%。复查时发现这是数据泄漏造成的假象——用会话级划分重新评估后，真实成绩是 85–93%。这篇记录泄漏的机制、修复方法，以及这个教训如何让"实验严谨性"变成了我最值钱的工程经验。

项目背景：一套便携 ECG 活动监测系统

树莓派 Zero W + AD8232 模拟前端 + MCP3008 (10-bit SPI ADC) 采集 ECG， 目标识别三类低强度活动：坐姿、上肢运动、步行。 采集 30 段 300 秒数据 → coif4 小波去噪 → CWT 生成时频图（scalogram） → AlexNet 迁移学习分类。

处理链路里最容易被忽视的环节，不是采集也不是模型——而是 训练/测试数据切分的正确性。

信号链路：从电极到特征图

/* 电极 → 模拟前端 → ADC → 小波去噪 → 时频图 → CNN */
Electrodes (3-lead)
   → AD8232 AFE (差分放大 + RLD + 0.5~40Hz 带通)
   → MCP3008 (10-bit @256Hz, SPI)
   → coif4 小波阈值去噪 (SNR 21.21dB, 50Hz 陷波)
   → CWT scalogram (400 样本窗口 = 1.56s)
   → AlexNet 迁移学习 (3 类活动)

为什么是小波而不是 FIR/IIR？

肌电噪声与 QRS 波群频带重叠，固定滤波器会把信号一起削掉。 小波在时频两域联合定位：噪声是高频小系数，用阈值函数衰减； 大系数（QRS 形态）原样保留。论文对比 db4/sym6/coif4 的 SNR = 21.17 / 21.19 / 21.21 dB，coif4 最高， 且其近似对称 + 高消失矩能更好保留 ECG 尖锐形态。

为什么变成图片再分类？

AlexNet 是 CNN，擅长图像。把一维信号变成二维时频图， 让网络学习"哪些频率在什么时间出现"——坐姿/运动/步行的 ECG 时频特征差异明显。 同参数下 scalogram 分类精度优于直接喂波形，因为时频域里噪声更易分离。

翻车现场：99.8% 是怎么"造假"的？

论文最初用 splitEachLabel(..., 'randomized') 在样本级随机切分。看起来天经地义，实际上埋了雷：

  1. 300s 连续信号切成 400 点（1.56s）窗口，相邻窗口共享信息
  2. 修正版切分甚至用了 50% 重叠——相邻窗口直接共享一半数据
  3. 样本级随机划分 → 同一段 300s 的材料必然同时出现在训练和测试集

结果是模型"背答案"：测试集里满是训练时见过的波形片段， 99.8% 的高分是对记忆力的奖励，不是对泛化能力的衡量。

修复：会话级划分（Session-Level Split）

正确做法是按会话（session）划分：10 段 300s 数据， 8 段训练、2 段测试，同一段材料的全部窗口只属于一侧—— 训练和测试在时间上彻底无重叠。 

// MATLAB · 会话级划分（修复数据泄漏）
rng(42);
train_sess = sort(randperm(10, 8));    % 8 段训练
test_sess  = setdiff(1:10, train_sess); % 2 段测试
// 每个 400 样本窗口按其来源会话 ID 归类，绝不错位
划分方式 准确率 含义
样本级随机划分（原论文） 99.8% 训练/测试时间上重叠，虚高
会话级划分（修复后） 85–93% 真正的泛化能力

85–93% 依然是不错的成绩，而且它经得起质疑—— 这才是简历上应该出现的数字。主动承认并修正，比守着虚假的 99.8% 有价值得多。

这次教训的 3 个工程启示

启示 1：泄漏不只发生在"切分"

复查时还发现一串连锁 bug：声称 256Hz 实际 ~139Hz（time.sleep 不精确）、 论文说 coif4 代码用 db3、CSV 格式与切分代码不匹配。 信号处理项目里，"报告的数字"与"实际代码"可能根本不是一回事—— 用数据反推验证（样本数 ÷ 时长 = 真实采样率）比相信注释可靠得多。

启示 2：时间序列的划分红线

// 时间序列 / 生理信号 ML 的铁律：
1. 相邻窗口天然相关 → 不重叠仍不独立
2. 按"个体 / 会话 / 试验"分组划分，而非按样本
3. 报告时注明划分粒度 —— 面试官一追问就知道你懂不懂

启示 3：诚实面对数字，把教训变成卖点

面试官最怕听到"准确率 99%+"却讲不清泛化边界。主动说： "我的模型从 99.8% 修正到 85–93%，因为发现了数据泄漏， 改用会话级划分重新评估"——这展示的批判性思维和实验严谨性， 是初学者最稀缺、企业最看重的特质。

后续：从学术验证走向嵌入式部署

论文目标"部署到树莓派"在毕业后补齐：用 TFLite INT8 量化 把 244MB 模型压到 ~61MB，推理时间从 3–5s 降到 ~1.5s， 在 1.56s 的帧周期内首次达到准实时。 还加了 Pan-Tompkins 提取心率，让系统从"分类器"升级为"生理监测仪"。

Metric FP32 INT8 Quantized
Model size ~244MB ~61MB
Inference / frame ~3–5s ~1.5s
Accuracy (session-level) ~93% ~90% (<3% loss)
Real-time vs frame period (1.56s) FAIL PASS

经验总结

  1. 时间序列/生理信号的 train/test split 必须按会话或个体——样本级划分几乎必然泄漏
  2. 用数据反推验证声明：采样率、波形、代码与论文不一致都能被算出来
  3. 迁移学习 + 小波去噪是生物电信号小样本问题的黄金组合
  4. INT8 量化的精度损失 <3%，换来 4× 体积缩小和 2–3× 加速——嵌入式 AI 的默认选择
  5. 诚实是最强的面试策略：敢于讲"我错在哪"比炫耀"我做得多好"更难、也更值钱
