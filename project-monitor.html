// Overview

An independent, product-grade portable power monitoring terminal measuring voltage (0–36V), current (0–2A), power, and accumulated energy with 0.1% design accuracy. Built to close the gap between textbook power electronics theory (SMPS simulation) and real hardware measurement.

独立完成的便携式电能监测终端，将大学 SMPS 电源理论落地为真实硬件测量工具。

// Key Technical Decisions

1. Why INA226 instead of ACS712?

Approach Principle Accuracy Use Case
ACS712 Hall effect ±1.5% Rough high-current sensing
Shunt + Op-Amp Differential amp Medium Custom design required
INA226 Shunt + 19-bit ΔΣ ADC 0.1% Industry-standard for power monitoring

INA226 directly samples bus voltage (VIN+ and VBUS pins) and computes power/energy in hardware — dramatically simplifying firmware. Used in DJI chargers, Anker fast chargers, and server PSUs.

2. Kelvin 4-Wire Sensing

The most important design detail. The shunt resistor's sampling path is routed separately from the main current path, eliminating PCB copper trace resistance errors. 

/* Kelvin connection */
Main current path : VIN+ ──→ Rshunt ──→ VIN-
Sampling path     : Kel+ ──→ ADC     ──→ Kel-

// Separate routing = zero copper trace error in measurement

3. INA226 Calibration

const float current_lsb = MAX_CURRENT / 32768.0f;  // 2.0A / 32768 = 61µA/bit
uint16_t calib = (uint16_t)(0.00512f / (current_lsb * RSHUNT));
// 0.00512 is INA226's internal calibration constant
INA226_WriteReg(REG_CALIB, calib);
