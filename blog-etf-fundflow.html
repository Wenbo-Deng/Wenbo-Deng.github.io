散户是"聪明钱"吗：ETF 资金流与次日收益的 34 天统计验证

Deng Wenbo · Quant · Python · Statistics · ~6 min read

"跟着主力资金走"是散户圈最流行的说法。我用 34 个交易日的 ETF 资金流数据，用相关系数和统计显著性检验了这个传言——结论既支持直觉，又提醒我样本量的重要性。

动机：把"感觉"变成"证据"

盯盘软件每天都在推"今日主力净流入"，但很少有人问： 今天的资金流，对明天的涨跌到底有没有预测力？ 我用 Python + Pandas 搭建了一个针对半导体设备 ETF（159516）的多因子分析工具， 前端是 技术面 + 资金面加权打分，但更值钱的是它背后的 相关性验证——先证明信号存在，再谈用它交易。

多因子加权模型

Factor Indicator Weight
MA Trend 5/10/20-day moving averages 30%
Fund Flow 主力净流入 (institutional flow) 35%
Bollinger Bands 20-day ±2σ 15%
RSI 14-period 10%
Sector ETF fund flow proxy 10%

资金面权重最高（35%），因为市场共识是"机构资金聪明"。但共识需要数据检验。

统计验证：资金流真的能预测次日收益吗？

采集 2026-06-17 至 2026-08-04 共 34 个交易日的资金流与行情数据， 计算两个相关性：

  • T 日资金流 vs T+1 日收益率 —— 我们要验证的"预测力"
  • T 日资金流 vs T 日指数涨跌 —— 作为对照组（同向）
Metric Value Interpretation
Correlation (T flow vs T+1 return) r = 0.2718 弱正相关
p-value (Pearson, n=34) 0.1101 不显著（样本有限）
Control: flow vs same-day index r = −0.7472 强负相关（"反向指标"效应）
流入日 → 次日上涨概率 55% 平均 +0.17%
流出日 → 次日上涨概率 33% 平均 −2.14%

关键发现

① 流入日与流出日的次日上涨概率差 22 个百分点 （55% vs 33%）——方向上支持"资金流有参考价值"。 ② 但 r=0.27 对应的 p=0.11 > 0.05——按统计标准这个相关不显著。 两者的统一解释是：样本量（34 天）太小，信号存在但置信区间太宽。

最有意思的是对照组：当日资金流与当日指数 r = −0.7472 强负相关—— 散户资金行为呈明显的"追涨杀跌"反向特征： 往往在当天大涨后流入、大跌后流出，恰好成了"追高"的注脚。

样本量是硬约束

// 临界相关系数（α=0.05, 双尾）
r_crit ≈ 1.96 / sqrt(n - 3)  ≈ 1.96 / sqrt(31) ≈ 0.35
// 我们的 r=0.27 < 0.35 → 不能拒绝"无相关"原假设
// 但方向一致 + 条件概率差 22pp → 值得扩大样本继续验证

34 天只是 1.5 个月的行情，横跨了单一行情阶段。真正的验证需要 覆盖牛熊、多个 ETF、几百个交易日。这也是我目前工具最大的已知局限—— 工具本身没有错，错的是"用太小的样本下结论"的冲动。

从验证到交易信号：加权打分

验证之后，把信号合成为 0–100 的打分：>60 偏多、<40 偏空，并输出次日高低点预测区间。 

def calculate_score(technical, fund_flow, boll, rsi, sector):
    score = (
        W_MA_TREND   * technical +
        W_FUND_FLOW  * fund_flow +
        W_BOLL       * boll +
        W_RSI        * rsi +
        W_SECTOR     * sector
    )
    return score  # 0-100, >60 → buy, <40 → sell

经验总结

  1. 先验证信号再谈交易：相关系数 + p 值把"感觉"变成可辩护的证据
  2. 对照组救了你：当日 r=−0.7472 揭穿了"散户聪明钱"的直觉误区
  3. p > 0.05 不代表没信号，也可能只是样本不足——要报告效应方向与置信度
  4. 量化工具要标明假设边界：34 天、单一行情、单一 ETF，结论不可外推
  5. 统计是工程严谨性的一部分：硬件工程师调信号链路，Quant 调的是数据与假设
